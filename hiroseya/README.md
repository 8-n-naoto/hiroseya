# 広瀬屋 Webサイト

岐阜県揖斐郡揖斐川町のうどん・そば処「広瀬屋」の公式サイト（CMS型）。

店舗の方が管理画面からコンテンツを更新するだけで運用できることを目標にしています。

- 設計の全体像は **[実装設計確定書 Rev.2](https://claude.ai/code/artifact/0b4fa6f6-ca0f-4ed3-ae12-20257fac3cc5)** を参照
- セットアップ手順は **[docs/SETUP.md](docs/SETUP.md)**
- 現在の実装状況は **[docs/STATUS.md](docs/STATUS.md)**

## 技術構成

| 層 | 採用 |
| --- | --- |
| フレームワーク | Laravel 13.x |
| PHP | 8.4（8.3 以上が必須） |
| DB | MySQL / MariaDB（ローカルは SQLite） |
| 公開サイト | Blade（サーバーサイドレンダリング） |
| 管理画面 | Blade + Alpine.js |
| キュー | database ドライバ + cron |
| 公開先 | エックスサーバー（共用） |

## いま入っているもの

DBスキーマ（23テーブル + users拡張）、Eloquentモデル、設定基盤、仮データのシーダーまで。
画面（管理画面・公開サイト）はこれからです。

## 注意

**シーダーが入れる営業時間・定休日・価格は仮の値です。**
実際の値に差し替えるまで、`site.preparation_mode`（準備中モード）を OFF にしないでください。
ONの間は全ページが noindex になり、誤情報が検索エンジンに登録されるのを防ぎます。
