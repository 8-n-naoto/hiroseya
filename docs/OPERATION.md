# 広瀬屋ホームページ 運用の手引き

管理画面を使う方（店舗のみなさま）向けの説明です。
専門用語はできるだけ使わずに書いています。

---

## 1. ログイン

`https://（サイトのURL）/login` を開き、メールアドレスとパスワードを入力します。

- パスワードを忘れたときは、ログイン画面の「パスワードをお忘れですか？」からメールで再設定できます。
- 5回続けて間違えると、しばらくログインできなくなります。時間をおいてお試しください。

---

## 2. 公開するまで

サイトは最初、**準備中モード**になっています。
この間、お客様には「ただいま準備中です」というページだけが表示され、
検索エンジンにも載りません。**中身が仮のまま検索結果に出てしまう事故を防ぐため**です。

ログインしている方には、準備中モードの間も本物のページが表示されます。
確認しながら中身を整えて、最後に準備中モードを解除してください。

やることは、**ダッシュボードのチェックリスト**にすべて出ています。
上から順に片付けて、印がすべて緑のチェック（✓）になったら、
「各種設定 → サイト基本」で「準備中モード」のチェックを外して保存します。

> ⚠️ **特に重要な2つ**
> - **営業時間**：初期値は仮の値（水曜定休・11:00〜14:00 / 17:00〜20:00）です。
>   必ず実際の営業時間に直してください。誤った営業時間が検索結果に載ると、
>   お客様が閉店中に来店されてしまいます。
> - **料理の価格**：初期データの価格は2019〜2021年頃のものです。現行価格に直してください。

## 3. よく使う操作

### お問い合わせに答える

「お問い合わせ」を開くと、未対応のものが上に並んでいます。
件名をクリックして、下の「お客様へ返信する」に文章を書いて送信してください。
送った内容は履歴として残ります。

- **通知メールが届かないとき**は、「各種設定 → メール」の設定が済んでいるかご確認ください。
- 通知メールにそのまま「返信」しても、お客様に直接届きます。
  ただし、管理画面から送ったほうが記録が残るのでおすすめです。

### 料理を追加する・価格を変える

「お品書き（料理）」→「料理を追加」。

- **価格は1品にいくつでも登録できます。**
  「単品」「セット」、「二枚」「三枚」、「小」「中」「大」のように名前を付けて並べてください。
- **店内とお持ち帰りで価格が違う品**は、提供区分を分けて2行登録します。
  こうしておくと、お持ち帰りのページにも自動で載ります。
- 「代表」に印を付けた価格が、お品書きの一覧に大きく出ます。
- **並び順**は一覧画面の ▲▼ で変えられます。変えたあと「並び順を保存」を押してください。

### 季節限定のメニュー

料理の編集画面の「提供期間」に開始日と終了日を入れておくと、
**期間が過ぎたら自動でお品書きから消えます。** 毎年手で消す必要はありません。

### 臨時休業を知らせる

「営業時間・臨時休業」の右側から、日付を選んで登録します。
サイトの表示だけでなく、Googleなどの検索結果に出る営業時間にも反映されます。

### お知らせを書く

「お知らせ」→「お知らせを書く」。

- 「公開日時」を**先の日時**にすると、その時刻になってから自動で公開されます。
  「明日の朝から出したい」というときに使ってください。
- 書きかけのときは「公開状態」を **下書き** にして保存しておけます。

### 写真を入れる

「画像ライブラリ」でまとめてアップロードしてから、
料理やお知らせの編集画面で「画像を選ぶ」を押して選びます。

- **代替テキスト**は、写真の中身を短く説明する文です（例：「土鍋に入った味噌煮込みうどん」）。
  目の不自由な方に読み上げられるほか、検索エンジンにも写真の内容が伝わります。
  面倒でも入れておくと、写真からの検索流入が増えます。
- アップロードすると、表示用の軽い画像が自動で作られます。
  スマートフォンで撮ったそのままの写真を上げていただいて構いません。

## 4. やってはいけないこと

- **公開したページの「URL（英数字）」は変えないでください。**
  URLが変わると、それまでに積み上がった検索エンジンの評価が失われ、
  他のサイトから貼られたリンクも切れます。
- **店名・住所・電話番号は、食べログやGoogleマップなど他の掲載先と同じ表記に揃えてください。**
  表記が割れていると、検索エンジンが同じ店だと判断できず、地図検索で上位に出にくくなります。
  （「広瀬屋」と「廣瀬屋」、「脛永」と「和田」のような揺れに注意）
- **すべてのページに同じタイトル・同じ説明文を入れないでください。**
  空欄にしておけば自動で作られます。同じ文言を並べるより、空欄のほうが良い結果になります。
- **すべての料理に詳細ページを作らないでください。**
  中身の薄いページを大量に作ると、サイト全体の評価が下がります。看板料理だけで十分です。

## 5. 権限

| | 管理者 | 編集者 |
|---|---|---|
| 料理・お知らせ・イベント・トップページ・画像 | ○ | ○ |
| お問い合わせの対応 | ○ | ○ |
| 店舗情報・営業時間 | ○ | × |
| SEO・メール・SNS・各種設定 | ○ | × |
| ユーザーの追加・削除 | ○ | × |

アルバイトの方などには「編集者」をお渡しください。
辞められたときは、削除ではなく**「利用を許可する」のチェックを外す**のがおすすめです。
これまでの操作記録が残り、次のアクセスで自動的にログアウトされます。

## 6. 困ったときは

| 症状 | 確認するところ |
|---|---|
| お問い合わせの通知メールが来ない | 各種設定 → メール（「通知の宛先」が空になっていないか）→ テスト送信 |
| お客様に自動返信が届かない | 同上。迷惑メールフォルダも確認 |
| 公開したはずのお知らせが出ない | 「公開状態」が公開か、「公開日時」が未来になっていないか |
| 料理がお品書きに出ない | 「公開状態」が公開か、「提供期間」が過ぎていないか、分類が「表示する」になっているか |
| お持ち帰りのページに出ない | その料理に「お持ち帰り」の価格が登録されているか |
| サイトが「準備中」のまま | 各種設定 → サイト基本 → 準備中モードのチェックを外す |
